# SafeAlert public information site

This repository contains only the static informational pages for SafeAlert. The app source and backend remain in the private [safealert-mobile-app repository](https://github.com/tyron40/safealert-mobile-app).

The site is an informational preview. The privacy and support pages are marked as drafts and are not the final app privacy policy or official support channel.

## GitHub Pages

GitHub Pages can serve these static files. It cannot run the mobile app API, database, authentication, SOS dispatch, or native iOS/Android builds.
