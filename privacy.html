Privacy information

Privacy matters.

This notice describes the SafeAlert informational website draft. It is not the final privacy policy for the SafeAlert mobile app.

Publication note: This page is a draft. Before release, the app owner must review the mobile app’s data flows, service providers, retention, and support contact, then publish a complete app privacy policy.

This website

The static site draft contains no sign-in, contact form, advertising, analytics, or embedded third-party scripts. It is intended to show informational pages only. The site is delivered through GitHub Pages; review GitHub’s privacy information for details about its hosting and security practices.

The mobile app

The app repository includes code for profile details, emergency contacts, location access, alerts, and community-related screens. This draft does not establish what information the released app collects, where it is sent, how long it is retained, or which service providers process it. Those details must be verified against the exact release build before this page is used as the app’s privacy policy.

Until that review is complete, do not treat this page as a statement that app data stays on-device or is never shared.

Safety note

SafeAlert is not an emergency dispatch service. For immediate danger or urgent medical help, call 911.
